# 配置

三份文件，都在 `config/` 下（可用 `--config` 或环境变量 `SNOWLINK_CONFIG` 换目录）：

| 文件 | 作用 | 与 SnowLuma 的关系 |
|---|---|---|
| `onebot_<uin>.json` | OneBot 网络（HTTP / WS / 反向 WS / 上报） | **字段完全一致**，可以直接拷过来 |
| `runtime.json` | WebUI 端口等 | 字段一致 |
| `webui.json` | WebUI 口令（sha512 + salt） | 格式一致 |
| `arklink.json` | 底层 ArkLink 地址与 token | 本实现新增 |

## onebot_<uin>.json

```json
{
  "mode": "snapshot",
  "networks": {
    "httpServers": [{
      "name": "http-default",
      "accessToken": "换一个随机串",
      "messageFormat": "array",
      "reportSelfMessage": false,
      "host": "127.0.0.1",
      "port": 3000,
      "path": "/",
      "enableWebSocket": false
    }],
    "httpClients": [],
    "wsServers": [{
      "name": "ws-default",
      "accessToken": "换一个随机串",
      "messageFormat": "array",
      "reportSelfMessage": false,
      "host": "127.0.0.1",
      "port": 3001,
      "path": "/",
      "role": "Universal"
    }],
    "wsClients": [],
    "httpClients": []
  },
  "statusCommand": {"enabled": false, "swallow": false, "cooldownSeconds": 5, "trigger": "#sl"},
  "historySync": {"enabled": false},
  "notifications": {"channelIds": []}
}
```

- `messageFormat`：`array`（段数组）或 `string`（CQ 字符串）。事件与动作都受它影响。
- `reportSelfMessage`：`true` 时把 `message_sent` 也推给你。
- `role`：`Universal` / `Api` / `Event`。`Event` 只收事件不回动作。
- `enableWebSocket`：HTTP 服务端上允许 WS 升级（同一个端口两种协议）。
- `path`：只匹配这个前缀；填 `/` 表示都收。

## 反向 WS / HTTP 上报

```json
"wsClients": [{
  "name": "nonebot",
  "url": "ws://127.0.0.1:8080/onebot/v11/ws",
  "accessToken": "框架侧配的 token",
  "messageFormat": "array",
  "reportSelfMessage": false,
  "reconnectInterval": 5
}],
"httpClients": [{
  "name": "report",
  "url": "http://127.0.0.1:8080/onebot/v11/http",
  "accessToken": "",
  "messageFormat": "array",
  "reportSelfMessage": false,
  "timeout": 5
}]
```

断线会按 `reconnectInterval` 秒重连，不会把进程拖死。

## runtime.json

```json
{
  "webuiPort": 5099,
  "webuiHost": "127.0.0.1",
  "hookAutoLoad": false,
  "trustProxy": "",
  "logMaxTotalMb": 1024,
  "logRetainDays": 7,
  "logPerUin": false,
  "appName": "SnowLink"
}
```

前七个字段与 SnowLuma 同名同义。`appName` 是本实现新增的：

- 默认 `"SnowLink"`，即 `get_version_info` 里如实上报自己是谁；
- 有些框架会按 `app_name` 分支（把 SnowLuma 当已知实现来适配），
  需要严格顶替时改成 `"SnowLuma"`，其他行为不变；
- 这不影响任何能力判断——能做与不能做只看能力矩阵，不看这个名字。

`webui.json`（口令哈希 + salt）和 `config/` 里的其他文件保持原格式，首次启动自动生成。

## arklink.json

```json
{
  "baseUrl": "http://127.0.0.1:6900",
  "token": "arklink env token 的输出",
  "uin": "你的QQ号",
  "timeout": 20,
  "offline": false
}
```

- 环境变量优先：`ARKLINK_BASE_URL` / `ARKLINK_API_TOKEN` 会覆盖文件里的值
  （适合 systemd 里用 `Environment=` 注入口令）。
- `offline: true` 或 `--offline`：不连 ArkLink，发送回显成事件，用来验证框架侧配置。
- token 在哪：宿主机（或虚拟机）执行 `arklink env token`；也可以在
  `~/.arklink/api.json` 里看 `"token"`。

## 多账号

一个账号一份 `onebot_<uin>.json`，与 SnowLuma 一致。当前**一个进程跑一个账号**，
要多账号就多起几个进程，端口和 WebUI 端口错开：

```bash
python -m snowlink run --uin 10001 --config config/a
python -m snowlink run --uin 10002 --config config/b
```

## 常见报错

| 现象 | 原因与处理 |
|---|---|
| `retcode: 1401` | token 不对。`arklink env token` 重新取，写进 `arklink.json` |
| `连不上 ArkLink` | `arklink serve api` 没起，或 baseUrl 写错（默认 6900） |
| `端口 3000 起不来` | 端口被占（比如 SnowLuma 正在跑）。改端口，或先停掉它 |
| 发图片返回 1404 | 通道只支持文本，见 [兼容性.md](兼容性.md) |
| WebUI 口令忘了 | 删掉 `config/webui.json`，重启，会重新生成并打印 |
| 框架连不上 WS（401） | `accessToken` 没带或不对；WS 也支持 `?access_token=` |
